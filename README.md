# 🧪 Dummy Data API (Laravel)

A powerful and easy-to-use **Dummy Data Providing API** built with **Laravel**.  
This API helps developers quickly generate and consume fake data for frontend development, testing, prototyping, and demos.

---

## ✨ Features

- 🚀 RESTful API built with Laravel
- 🎭 Fake data generation using **FakerPHP**
- 📦 Multiple dummy resources (Users, Products, Posts, etc.)
- 🔄 Pagination, limits, and filtering support
- ⚡ Fast and lightweight
- 🧪 Ideal for frontend & mobile app development
- 🛠 Easy to extend with custom data schemas

---

## 🎯 Use Cases

- Frontend UI development
- Mobile app API integration
- Automated testing
- Prototyping and demos
- Learning REST API concepts

---

## 🧰 Tech Stack

- **PHP** >= 8.0
- **Laravel** (latest stable)
- **FakerPHP**
- **Composer**
- **MySQL / SQLite** (optional)
